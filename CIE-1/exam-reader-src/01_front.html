📖 Pass 1 — understand (≈ 3 hrs)
Read slowly from start to end. Read the "In plain words" box first, then the rest. At each diagram, stop and say out loud what each arrow means. Don't try to memorise yet.
⚡ Pass 2 — lock it in (≈ 1.5 hrs)
Read only the definitions, bold words, highlights, tables and 🧠 tricks. For the diagrams marked ✏️ must-draw, cover the figure and draw it from memory.
