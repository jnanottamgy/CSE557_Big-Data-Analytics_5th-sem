How each answer is sized

MarksLengthWhat to write
2 MARKS3–4 linesA crisp definition + one key point or example. No diagram needed.
3 MARKS3 points / ~6 linesThree clear points (or a 3-row table). A small diagram if it helps.
5 MARKS¾ – 1 pageDefinition → diagram → 4–6 numbered points → example. The grey "marks split" line under each answer shows where the marks usually go.
🎯 Exam-hall tips
  • Start long answers with the exact definition — it earns the first mark immediately.
  • Draw the diagram early in a 5-mark answer and label every box and arrow; number the arrows for step-based topics.
  • Use headings and numbered points, not paragraphs — examiners scan for keywords.
  • A 3-mark "differentiate" question → answer as a 3-row table.
  • Don't over-write 2-markers — save time for the 5-markers.
