2.1Installing Apache Spark (Ubuntu)from textbook@@s2-1@@

🗣 In simple words
Spark runs on Java, so install Java first. Then download Spark, unzip it, tell your terminal where it is (environment variables), and start the pyspark shell to check it works. That's it — no cluster needed; one laptop is enough to learn.

# 1. Prerequisite: Java (and Python 3 for PySpark)
sudo apt update
sudo apt install -y openjdk-11-jdk python3
java -version                                  # check Java is installed

# 2. Download a pre-built Spark package from spark.apache.org/downloads
wget https://archive.apache.org/dist/spark/spark-3.5.1/spark-3.5.1-bin-hadoop3.tgz

# 3. Extract it and move it to /opt/spark
tar -xzf spark-3.5.1-bin-hadoop3.tgz
sudo mv spark-3.5.1-bin-hadoop3 /opt/spark

# 4. Set environment variables (add these lines to ~/.bashrc)
export SPARK_HOME=/opt/spark
export PATH=$PATH:$SPARK_HOME/bin:$SPARK_HOME/sbin
export PYSPARK_PYTHON=python3
source ~/.bashrc

# 5. Verify
spark-shell --version                          # prints the Spark version banner
pyspark                                        # opens the Python shell with 'spark' and 'sc' ready
💡 Even quicker: pip
For Python-only use on one machine: pip install pyspark — this installs Spark inside Python. You still need Java installed.

2.2Writing your first Spark programfrom textbook@@s2-2@@

A. Interactively in the shell

The textbook's first program loads Spark's own README.md as a text file and asks simple questions about it.

In pyspark (Python)

>>> lines = sc.textFile("README.md")   # an RDD of lines
>>> lines.count()                  # action → job
125
>>> lines.first()                  # first line
'# Apache Spark'
>>> spark_lines = lines.filter(
...     lambda l: "Spark" in l)        # transformation
>>> spark_lines.count()
20

In spark-shell (Scala)

scala> val lines = sc.textFile("README.md")
scala> lines.count()
res0: Long = 125
scala> lines.first()
res1: String = # Apache Spark
scala> val sparkLines =
     |   lines.filter(l => l.contains("Spark"))
scala> sparkLines.count()
res2: Long = 20

(The exact numbers depend on the Spark version's README.)

💡 Connect it to the architecture
textFile() and filter() only record steps in the DAG — nothing runs. count() and first() are actions: each one creates a job, which the DAG Scheduler splits into stages and tasks (one per partition) that run on executors (§1.6). Transformations vs actions are studied in detail after CIE-1.

B. A standalone application — word count

A real application creates its own SparkSession (the shell did it for you before). Save this as wordcount.py:

from pyspark.sql import SparkSession

# 1. Create the entry point (driver creates SparkSession / SparkContext)
spark = (SparkSession.builder
         .appName("WordCount")
         .master("local[*]")        # run locally using all CPU cores
         .getOrCreate())
sc = spark.sparkContext

# 2. Load data → 3. transform → 4. action
lines  = sc.textFile("input.txt")
words  = lines.flatMap(lambda line: line.split())     # split lines into words
pairs  = words.map(lambda w: (w, 1))                  # (word, 1) — like a mapper
counts = pairs.reduceByKey(lambda a, b: a + b)        # add up — like a reducer

for word, n in counts.collect():                        # action → runs the job
    print(word, n)

# 5. Stop — terminates executors, releases resources (run-time step 10)
spark.stop()

Run it with spark-submit:

spark-submit wordcount.py
# or choose where it runs:
spark-submit --master local[4] wordcount.py
📌 Same idea as Unit 2
This is the classic word count: map emits (word, 1) like a Mapper, reduceByKey sums them like a Reducer — but in about 6 lines instead of three Java classes, and the data stays in memory between steps.

2.3Apache Spark cluster manager types@@s2-3@@

From the slides: the cluster manager's role is to allocate resources across applications. Spark has its own standalone cluster manager, and can also work with Hadoop YARN and Apache Mesos. from textbook Spark 2.3+ also supports Kubernetes, and local mode runs everything on one machine.

Figure 2.1 — Cluster manager types for Spark (slides list Standalone, YARN and Mesos)
🖥 Local mode

Driver and executor run in one JVM on one machine — no real cluster. Used for learning, development and testing (your Ubuntu lab setup). Master URL: local (1 thread), local[4] (4 threads), local[*] (all cores).

⭐ Standalone cluster manager

Spark's own simple cluster manager, shipped with Spark. Makes it easy to set up a cluster on an empty set of machines. One master + several workers. Start with sbin/start-master.sh then sbin/start-worker.sh spark://<master>:7077. Master UI on port 8080. Master URL: spark://HOST:7077.

🐘 Hadoop YARN

The resource manager of Hadoop 2 (Unit 2!). Lets Spark run on an existing Hadoop cluster, sharing resources with MapReduce and reading data from HDFS. The YARN ResourceManager acts as the cluster manager; executors run in YARN containers. Master URL: yarn.

🏛 Apache Mesos

A general-purpose cluster manager that can run Spark alongside other frameworks (and also Hadoop MapReduce). Supports fine-grained sharing of resources. Master URL: mesos://HOST:5050. (Deprecated in newer Spark versions.)

☸️ Kubernetes from textbook / docs

Runs the driver and executors as pods (containers) on a Kubernetes cluster. Master URL: k8s://https://HOST:PORT.

Master URLs at a glance

--master valueRuns on
localLocally with one worker thread (no parallelism)
local[K]Locally with K worker threads (e.g., local[4])
local[*]Locally with as many threads as CPU cores

2.4Running Spark examplesfrom textbook@@s2-4@@

Spark ships with ready-made examples in the examples/ folder. Running them is the easiest way to check your installation and see a cluster at work.

SparkPi — estimating π

# Scala/Java examples: use run-example (the argument = number of partitions/slices)
./bin/run-example SparkPi 10
…  Pi is roughly 3.1418

# Python version of the same example: use spark-submit
./bin/spark-submit examples/src/main/python/pi.py 10
Pi is roughly 3.140960
📌 How SparkPi works (simple idea)
Throw lots of random "darts" at a 1×1 square. The fraction that land inside the quarter-circle ≈ π/4, so π ≈ 4 × (inside ÷ total). Spark splits the darts into 10 partitions → 10 tasks that run in parallel on executors, then adds up the counts. More partitions = more parallel tasks.

Word count example

./bin/spark-submit --master local[4] examples/src/main/python/wordcount.py README.md

Running an example on different cluster managers

# Local (all cores)
./bin/spark-submit --master local[*]            examples/src/main/python/pi.py 100
# Standalone cluster
./bin/spark-submit --master spark://master:7077 examples/src/main/python/pi.py 100
# YARN, driver inside the cluster
./bin/spark-submit --master yarn --deploy-mode cluster examples/src/main/python/pi.py 100
💡 Watch it run
While an example runs, open http://localhost:4040. You'll see the job created by the action, its stages, and the 10 tasks — the terminology from §1.3 made visible.
