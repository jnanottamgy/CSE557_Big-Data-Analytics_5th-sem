How to use this guide

Unit 3 is about Apache Spark — the faster successor to Hadoop MapReduce. For CIE-1 you need only the first block of the syllabus: what Spark is, how its architecture works, and how to install and run it. You already know Hadoop from Unit 2, so this guide keeps comparing Spark with it.

CIE-1 covers CO1–CO3: Unit 1, Unit 2 and the first part of Unit 3. CO3 is "Apply Apache Spark programming concepts … and cluster management". The questions most likely from this part are "Explain the Spark architecture with a neat diagram", "Explain the components of Spark", "Explain the run-time flow of a Spark application" and "Explain the cluster manager types".
